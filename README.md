# Khmer Movie Flutter App

A beginner-friendly Flutter movie catalog.

## Included features
- Movie poster grid
- Search movies by title
- Filter by category
- Add and remove favorites
- Movie details screen
- Home and Favorites navigation

## Open and run
1. Extract `khmer_movie_app.zip`.
2. Open the extracted `khmer_movie_app` folder in VS Code.
3. Make sure Flutter is installed.
4. Open the VS Code terminal in the project folder.
5. Run:

```bash
flutter pub get
flutter run
```

Movie poster images load from the internet, so an internet connection is needed.

Favorites are stored in memory only and reset when the app restarts. This starter project does not include user accounts or movie streaming.
